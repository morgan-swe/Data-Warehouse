# Cleaning Data

We always want to check if our data is free of issues.

## Observations

### Checking for nulls or duplicates
 
One of the most common problems inside of data are null values and duplicate keys. 

We can look for null values and duplicate entries using the following method:

SELECT
(table_name),
COUNT(*)
FROM (schema_name).(info_file)
GROUP BY (table_name)
HAVING COUNT(*) >1

This brings up a table with all of the id's that have duplicate values as well as id's that are null.

### Cleaning nulls or duplicates

After finding all of the nulls and duplicates we can clean the data by focusing on a single value inside of the table that was generated by the checking method.

SELECT
*
FROM (schema_name).(table_name) 
WHERE (table_name) = (id_number)

When looking at duplicate values we can check for the creation date of the data, then we can rank all of the duplicate entries by the date that they were created. The most recently created file will be ranked the highest, thus we pick the highest ranked data and remove all of the older entries.

We can rank all of the entries pertaining to the data using the following method:

SELECT
*,
ROW_NUMBER() OVER (PARTITION BY cst_id ORDER BY cst_create_date DESC) as flag_last
FROM (schema_name).(table_name) 
WHERE (table_name) = (id_number)

### Removing unwanted spaces

We can check for unwanted spaces using the following method:

SELECT (table_name)
FROM (schema_name).(filename)
WHERE (column) != TRIM(column)

We can then clean the data using the following method:

SELECT 
cst_id,
cst_key,
TRIM(cst_firstname) AS cst_firstname,
TRIM(cst_lastname) AS cst_lastname,
cst_lastname,
cst_marital_status,
cst_gndr,
cst_create_date
FROM (
	SELECT 
	*,
	ROW_NUMBER() OVER (PARTITION BY cst_id ORDER BY cst_create_date DESC) as flag_last
	FROM bronze.crm_cust_info
	WHERE cst_id IS NOT NULL
)t WHERE flag_last = 1
