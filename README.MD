# Data Warehouse

## This data science project will contain:

Data Warehousing:

- ETL/ELT processing
- Data architecture
- Data integration
- Data cleansing
- Data load
- Data modeling

Exploratory Data Analysis (EDA):

- Basic queries
- Data profiling
- Simple agregations
- Subquery

Advanced Data Analytics:

- Complex queries
- Window functions
- CTE
- Subqueries
- Reports

## DataBase

The database used for this project will be Microsoft SQL Server.
